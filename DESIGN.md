# DESIGN.md

Дизайн-система сайта Анастасии Райцевой. Файл лежит в корне проекта, чтобы любой агент, который берётся за вёрстку, сначала прочитал его и не изобретал свой вид.

**Источник системы:** карусели Анастасии для Instagram, сентябрь 2026. Сайт должен выглядеть их продолжением: человек, увидевший карусель и перешедший по ссылке, должен узнать то же оформление.

**Цвета подтверждены Анастасией 02.09.2026.** Шрифты подобраны по рисунку каруселей: если в макете стоят другие, заменить в разделе 3 и в `css/style.css`.

---

## 1. Настроение

Редакционный разворот, а не лендинг. Тёмная страница, на ней светлые карточки, как листы бумаги на столе. Крупные заголовки капсом, много воздуха внутри карточек, один тёплый акцентный цвет и ничего больше.

Три слова: **плотно, тепло, без украшений.**

Чего в этом настроении нет: свечения, стекла, градиентов, теней-ореолов, иконок ради иконок. Контраст создаётся размером и цветом бумаги, а не эффектами.

---

## 2. Палитра

Шесть цветов. Седьмого не заводить.

```css
:root {
    --ink:        #17161B;  /* фон страницы, тёмные карточки, текст на кремовом */
    --paper:      #F4EFE7;  /* кремовые карточки, текст на тёмном */
    --accent:     #C8623C;  /* терракота: второе слово заголовка, подчёркивания */
    --muted-dark: #8B8894;  /* серый текст на тёмном фоне */
    --muted-light:#6E6A66;  /* серый текст на кремовом */
    --line:       rgba(23, 22, 27, 0.12);  /* разделители на кремовом */
}
```

**Как применяются.**

| Роль | Цвет |
|---|---|
| Фон страницы | `--ink` |
| Карточка-лист | `--paper` |
| Заголовок на карточке | `--ink`, второе слово `--accent` |
| Основной текст на карточке | `--ink` |
| Вложенный блок внутри карточки | `--ink`, текст `--paper` |
| Служебная строка сверху | `--muted-dark` |
| Кнопка на карточке | фон `--ink`, текст `--paper` |
| Кнопка на тёмном фоне | фон `--paper`, текст `--ink` |

**Терракота работает только точками.** Одно слово в заголовке, подчёркивание под заголовком, стрелка. Никаких терракотовых заливок на пол-экрана, никаких градиентов из неё.

## 3. Типографика

Две гарнитуры, обе с кириллицей, обе с Google Fonts.

```html
<link href="https://fonts.googleapis.com/css2?family=Oswald:wght@500;700&family=Golos+Text:wght@400;500;600&display=swap" rel="stylesheet">
```

- **Oswald**, заголовки. Узкий тяжёлый гротеск, всегда капсом.
- **Golos Text**, весь остальной текст. Русский шрифт, рассчитан на чтение с экрана.

Если в макете другие шрифты, заменить здесь и только здесь.

| Уровень | Шрифт | Размер | Начертание | Регистр |
|---|---|---|---|---|
| Заголовок экрана | Oswald | 3.2-4.5rem | 700 | КАПС |
| Заголовок раздела | Oswald | 2-2.6rem | 700 | КАПС |
| Подзаголовок блока | Golos Text | 1.05rem | 600 | обычный |
| Основной текст | Golos Text | 1rem | 400 | обычный |
| Служебная строка | Golos Text | 0.85rem | 400 | обычный |
| Кнопка | Golos Text | 0.9rem | 600 | КАПС |

**Правила набора.**

- Заголовки капсом, межбуквенное расстояние не увеличивать: Oswald и так узкий.
- Заголовок в две строки, второе слово терракотовое. Это главный приём системы.
- Межстрочное расстояние в основном тексте 1.55-1.65. Тесно набранный текст на кремовом читается плохо.
- Строка основного текста не длиннее 70 знаков.
- **Длинных тире не ставить нигде.** Это общее правило проекта, не только дизайна.
- Кавычки только «ёлочки».

## 4. Компоненты

### Карточка-лист

Основная единица. Всё содержимое страницы живёт внутри таких карточек.

```css
background: var(--paper);
border-radius: 28px;
padding: 44px 48px;
```

На мобильном скругление 20px, поля 24px.

Внутри карточки бывает **вложенный тёмный блок** (как список услуг в карусели «Что я делаю»): фон `--ink`, скругление 16px, поля 18px 22px, заголовок `--paper`, пояснение `--muted-dark`.

### Кнопка-пилюля

```css
border-radius: 999px;
padding: 16px 28px;
font-weight: 600;
text-transform: uppercase;
```

Внутри текст и длинная стрелка `→`. При наведении стрелка сдвигается вправо на 4px, больше ничего не происходит. Кнопка не растёт, не подпрыгивает, не меняет цвет на градиент.

### Служебная строка

Тонкая строка над содержимым, как в каруселях: слева `@_hawkey_17`, справа `разработка · 1С · боты · сайты`. Цвет `--muted-dark`, размер 0.85rem. Разделитель точка-посередине, не дефис.

### Фигура в шапке

Фото слева, взгляд направлен в текст. Числа взяты из макета `design/hero-block 1.svg`: прямоугольник `x=81.34 y=-70 w=471.78 h=589.73`, поворот **6,948 градуса вокруг левого верхнего угла**.

Координаты в макете отсчитываются от края страницы, а карточка начинается с 24 по горизонтали и с 64 по вертикали, поэтому в стилях они смещены на эту величину. Файл обрезан по фигуре, и размеры пересчитаны под обрезку, отсюда дробные значения и отрицательная точка вращения.

Такая раскладка держится на точных пикселях и живёт только на полной ширине. **Ниже 1024 фигура возвращается в поток** и крутится вокруг своей подошвы.

**Знак угла в CSS обратный тому, что показывает Figma.** В Figma положительное вращение идёт против часовой стрелки, в CSS по часовой. Значит «минус 6,95» в макете это `rotate(6.95deg)` в стилях. На этом уже спотыкались.

Файл обрезан по фигуре, без прозрачных полей, иначе ограничение по высоте режет пустоту, а не картинку.

### Галерея работ

Карточки работ на тёмном фоне: снимок страницы сверху, под ним название и одна строка описания. Скругление 20px, подпись про демонстрационный характер обязательна.

## 5. Макет и отступы

- Ширина содержимого 1100px, узкие блоки 760px.
- Шаг отступов кратен 4: 8, 12, 16, 24, 32, 48, 64, 96.
- Между разделами 96px, на мобильном 56px.
- Поля страницы 24px.
- **Асимметрия приветствуется.** Заголовок можно прижать вправо, как на первом слайде карусели. Ровная колонка по центру на каждом экране это признак шаблона.

---

## 6. Глубина и тени

**Теней нет.** Совсем.

Слои различаются цветом бумаги: тёмная страница, светлая карточка, тёмный блок внутри карточки. Этого достаточно. Если возникает желание добавить `box-shadow`, значит, неверно выбран цвет подложки.

Единственная допустимая граница: `1px solid var(--line)` между строками внутри кремовой карточки.

---

## 7. Движение

Один переход: `0.2s ease` на цвет и на сдвиг стрелки в кнопке.

Запрещено: появление при прокрутке, параллакс, пружины, отскоки, увеличение карточек при наведении, счётчики цифр, печатающийся текст, мигающий курсор.

---

## 8. Адаптивность

Четыре порога, все в конце `css/style.css`.

| Ширина | Что меняется |
|---|---|
| до 1024px | поля карточек 36px, фото в шапке до 240px, работы от 250px в колонке |
| до 860px | шапка в одну колонку: текст сверху, фото под ним слева |
| до 760px | поля 22px, скругление 20px, кнопки на всю ширину, работы в одну колонку |
| до 400px | служебная строка и факты в столбик, этапы без колонки с номером |

Базовая ширина проверки 375px.

- Карточки на всю ширину минус поля, скругление 20px.
- Заголовок экрана не крупнее 2.4rem, иначе слово переносится по слогам.
- Галерея работ в одну колонку.
- Кнопка на всю ширину карточки.
- Ничего не прячется под «показать ещё»: страница короткая, прокрутить дешевле, чем нажать.

## 9. Антипаттерны

Список составлен по [no-slop-ui](https://github.com/LeoStehlik/no-slop-ui) и по разбору прежней версии сайта. **Каждый пункт был на сайте или чуть не появился.**

Запрещено:

1. **Градиенты** любые: в фоне, в тексте, в кнопках, в рамках.
2. **Свечение и ореолы** вокруг элементов, `box-shadow` с цветным размытием.
3. **Стеклянные панели**, `backdrop-filter: blur`.
4. **Иконки в кружках** над каждой карточкой. Иконка допустима только внутри кнопки или строки контакта.
5. **Ряд крупных цифр** под заголовком, если эти цифры нельзя проверить.
6. **Выдуманные числа** вообще: «30+ проектов», «98% довольных клиентов», «работаю 24/7».
7. **Макет окна редактора с кодом** и прочие декоративные скриншоты того, чего нет.
8. **Значки «доступна для заказов»**, мигающие точки, счётчики свободных мест.
9. **Четыре одинаковые карточки в ряд**, различающиеся только иконкой и заголовком.
10. **Холодная сине-фиолетовая палитра.** Акцент один и тёплый.
11. **Продающая лексика:** автоматизация, оптимизация, внедрение, под ключ, конверсия, лиды, комплексное решение, технический партнёр, помогаю зарабатывать больше.
12. **Обещания результата.** Считать можно только ту арифметику, которую читатель проверит сам.
13. **Стоковые фотографии людей** в офисе. Только свои снимки и снимки своих работ.

## 10. Проверка перед сдачей

Снять страницу и сверить координаты блоков с макетом:

```
py design\shot.py 1200        первый экран на полной ширине
py design\shot.py 375         узкий экран
py design\shot.py 1200 full   вся страница целиком
```

Скрипт печатает рамки блоков и ругается, если страница шире окна. Снимки складывает в `design/snapshots`. Судить о вёрстке по описанию, не глядя на неё, нельзя.


Прогнать страницу по списку раздела 9 и ответить по каждому пункту. **Если не прошло два пункта и больше, страницу переделывать, а не править точечно.**

Отдельно проверить:

- [ ] длинных тире нет ни одного
- [ ] все числа на странице проверяемы
- [ ] шрифтов ровно два
- [ ] цветов не больше шести
- [ ] теней нет
- [ ] на 375px ничего не уезжает за край
- [ ] карусели и сайт узнаются как одно оформление
